# Runtime dependencies for the knowledge-graph-builder Spark job.
#
# Install into the Spark Python environment on every worker. rdflib is used
# on executors (Turtle parsing UDF) and the driver; torch / torch-geometric
# are used on the driver for HeteroData assembly and torch.save; pandas /
# pyarrow back the driver's Arrow-optimized toPandas() collection in the PyG
# feature build; boto3 is used on the driver to read optional definitions from
# S3 and to mirror final artifacts to an S3 archive.
#
# NOTE: install torch / torch-geometric from the wheel index matching your
# cluster's GPUs and CUDA version (see the PyTorch and PyG install guides).
# The ceilings below are intentionally open so a CUDA-matched build can be used.

torch>=2.5.0
torch-geometric>=2.6.0
pandas>=1.0.5
pyarrow>=4.0.0
boto3>=1.28.0
